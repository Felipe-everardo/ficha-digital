# Roteiro de demonstração do MVP

Este roteiro valida o fluxo principal da Ficha Digital com a equipe do estúdio.
A demonstração deve utilizar somente dados fictícios. O projeto ainda não está
preparado para receber dados pessoais ou informações de saúde reais.

## Objetivo

Observar se o fluxo resolve o problema das fichas em papel e identificar os
próximos ajustes a partir do uso, antes de ampliar o produto.

## Preparação

- executar a API e o frontend;
- confirmar que o banco está atualizado;
- entrar com uma conta profissional de desenvolvimento;
- abrir uma janela anônima para representar o celular do cliente;
- avisar aos participantes que nomes, contatos e respostas devem ser
  inventados.

## Cenário sugerido

Use uma personagem fictícia, por exemplo:

- nome: Marina de Teste;
- celular: (21) 99999-0000;
- e-mail: marina.teste@example.com;
- respostas de saúde: inteiramente inventadas.

### 1. Área profissional

1. Entre na área profissional.
2. Cadastre a cliente fictícia.
3. Abra a lista de clientes.
4. Gere um novo convite.
5. Copie o link apresentado.

### 2. Experiência do cliente

1. Abra o link em uma janela anônima ou em outro celular.
2. Confirme se as orientações estão claras.
3. Preencha o questionário com respostas fictícias.
4. Leia e aceite o termo de demonstração.
5. Confirme a mensagem de conclusão.

### 3. Retorno ao profissional

1. Volte à área profissional.
2. Abra a lista de fichas.
3. Confirme que o estado mudou para `Concluída`.
4. Abra os detalhes da ficha.
5. Verifique se os dados fictícios foram apresentados de forma compreensível.

## Perguntas para o estúdio

- Quem normalmente inicia o cadastro do cliente?
- Em qual momento o link deve ser enviado?
- Os nomes dos campos estão claros para clientes e profissionais?
- Quais estados da ficha são realmente úteis no dia a dia?
- O profissional precisa reenviar, cancelar ou renovar um convite?
- Quais dados do procedimento devem ser preenchidos pelo profissional?
- Mais de um profissional atenderá o mesmo cliente?
- Qual confirmação o estúdio espera receber quando a ficha for concluída?
- O envio por copiar e colar é suficiente no MVP ou precisa de integração com
  um aplicativo de mensagens?

## Registro do resultado

Após a demonstração, registre:

- dificuldades observadas sem orientar o participante imediatamente;
- dúvidas repetidas;
- etapas consideradas desnecessárias;
- informações que fizeram falta;
- melhorias indispensáveis antes de uma segunda demonstração;
- ideias que podem permanecer fora do MVP.

Nenhuma informação real de clientes deve ser incluída nesse registro.

## Limite desta fase

A aprovação do fluxo pelo estúdio não autoriza o uso com clientes reais. Antes
da operação real ainda serão necessários, entre outros pontos, revisão jurídica,
backups, recuperação de conta, auditoria, política de retenção, monitoramento e
preparação da hospedagem.
